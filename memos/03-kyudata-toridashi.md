# 旧データの取り出し方
このメモは、旧システムの画面からファイルを取り出す手順です。新しい在庫管理へ入れるときの使い道も分けて書いています。確認できていない取得コマンドやAPIのアドレスは載せていません。
## 用途の区別
1. 旧在庫JSONと旧顧客JSONは、ブラウザの開発者ツールで、表示中の応答を Copy response して JSON ファイルとして保存します。
2. 商品台帳CSVは、画面のDOMから取る別の用途です。JSONの Copy response とは別です。正確なコマンドは記録の確認後にこのメモへ足します。今はコマンドを載せていません。
## 実行する画面
旧システムで、取り出したい一覧（在庫、または顧客）が表示されている画面です。F12 で開発者ツールを開き、Network を選んでから一覧を読み込みます。
## 旧在庫JSON
在庫の応答だけを保存します。顧客の応答と混ぜません。
```
F12
Network
対象の応答を選ぶ
Copy response
```
1. 旧システムの在庫一覧が表示される画面を開く。
2. F12 で開発者ツールを開き、Network を選ぶ。
3. 在庫の一覧を読み込む（画面の再読み込みでよい）。
4. 在庫データの応答を選ぶ。
5. その応答を Copy response する。
6. テキストエディタに貼り、拡張子 .json で保存する。
保存したファイルは、新しいシステムの初期在庫の登録で旧在庫JSONとして選びます。商品登録で選ぶ場合は、通常仕入先とメイン候補の判定だけに使い、在庫数量・単価・旧QRは書きません。
## 旧顧客JSON
顧客の応答だけを、旧在庫とは別に保存します。手順は旧在庫JSONと同じで、選ぶ応答が顧客の一覧です。
```
F12
Network
対象の応答を選ぶ
Copy response
```
1. 旧システムの顧客一覧が表示される画面を開く。
2. F12 で開発者ツールを開き、Network を選ぶ。
3. 顧客の一覧を読み込む。
4. 顧客データの応答を選ぶ。
5. その応答を Copy response する。
6. テキストエディタに貼り、拡張子 .json で保存する。
保存したファイルは旧顧客JSONです。旧在庫の顧客IDを、名前が一致する登録済み顧客へ対応するために使います。任意です。選ばないときは、保存済みの対応と、取り込み画面で選んだ手動対応を使います。顧客の新規作成や、住所・電話の書き換えには使いません。
## 商品台帳CSV（別用途）
商品台帳は、上の Copy response では取りません。画面のDOMからCSVを取る別手順です。正確なコマンドは、記録を確認してからこの下へコードとして載せます。それまでコマンド欄はありません。
