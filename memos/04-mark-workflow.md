# マーク管理の作業手順

2026年11月11日整理。締め処理の確認と、説明動画の構成に使う手順メモ。

## 作業の流れ

1. シフト表を作り、Touch On Timeの勤務予定を設定する。
2. 15日締めでTouch On Timeの実績を確認し、提出用の共有Excel出勤簿を完成させる。
3. 出勤日数・休日数・有休残数を確認する。
4. 月末に備品棚卸を行い、月末在庫を保存する。
5. 翌月10日の幹部会議に向けて報告をPDFにし、幹部会議フォルダーへ保存する。
6. 日々の圧着カウンターの記録を、対象月の圧着数として報告に使う。

## シフト準備

1. マーク管理 → シフト準備 → シフト表・予定CSVを開く。
2. 対象年月を確認し、出勤・休みなどの予定を入力してシフトを保存する。
3. Touch On Time用CSVを出力し、内容と対象期間を確認する。
4. Touch On Time側で予定を取り込み、設定されたスケジュールを確認する。

動画では、対象年月の選択、シフト入力、保存、予定CSVの出力、Touch On Time側の確認を順に撮影する。

## 15日締め — 実績の取込と提出用Excel

対象期間は前月16日〜当月15日。シフトの末日あたりから締めの作業を行う。

1. Touch On Timeから、対象期間の出勤簿の日別実績CSVを出力する。
2. マーク管理 → 15日締め → Touch On Time実績・コピーを開く。
3. CSVを選び、従業員と締め月を選択して「貼り付け内容を確認」を押す。
4. 16日〜15日の始業・休憩・終業を確認し、入力欄で必要な修正を行う。休憩の補完や始業の丸めを使う場合は、反映後の値も確認する。
5. 本人・期間・時刻・空欄の日を確認し、確認欄にチェックを入れる。
6. 「出勤簿用にまとめてコピー」を押す。
7. 提出用の共有Excel出勤簿を開き、表示された期間の初日の「始業時間」セルを選んで値のみ貼り付ける。
8. 共有Excelで氏名・期間・時刻・計算結果を確認して保存する。
9. 15日締め → 共有出勤簿の取込で、保存した共有出勤簿から更新する。
10. 日別・出勤日数で対象者と月を選び、出勤日数と有休の合計を確認・保存する。
11. 有休残数の取込で管理簿Excelを選び、従業員と集計セルの対応を確認する。現保有数を更新し、読み込んだデータを出勤簿に反映する。
12. 出勤簿・休日数の確認で、出勤日数、休日数、有休残数、勤務時間を確認する。

共有出勤簿の読取元設定は「共有出勤簿の取込」にある。提出用Excelの貼り付け先と、登録した読取元の対象者・年度を合わせる。

動画では、CSV選択から共有Excelの貼り付け・保存までと、アプリに戻って日数・有休残数を確認するところを一続きで撮影する。

## 月末締め — 備品棚卸

1. マーク管理 → 月末締め → 備品棚卸を開く。
2. 対象年月を確認し、「棚卸用紙を印刷」で数えるためのシートを用意する。
3. 実物を数えてシートに数量を記入する。
4. 備品棚卸の同じ対象月で、月末在庫の数量を入力する。
5. 購入数量の自動記録、月初在庫、月末在庫、当月使用を確認する。
6. 「保存」を押し、保存済みになったことを確認する。

動画では、棚卸用紙の出力、実棚数量の記入例、月末在庫への入力、保存を撮影する。

## 10日 幹部会議 — 報告書の作成とPDF保存

1. マーク管理 → 10日 幹部会議 → 幹部会議報告・PDFを開く。
2. 報告対象月を確認する。初期表示は前月で、例えば11月10日の会議なら10月分を選ぶ。
3. ユニフォーム契約の新規分・入替分について、顧客名・作業期間・備考を入力し、契約枠を保存する。
4. 月別集計は年度開始の2月から対象月までの数字を使う。必要に応じて「月別集計」で元の数字を確認する。
5. 対象月の備品棚卸が保存されていることを確認する。
6. 対象月の1日〜末日の日別カウンター値・圧着数と月合計を確認する。圧着数は記録ごとのカウンター差分の合計で、月初の差分には前の記録を使う。計算できる記録がない場合は「集計できる記録なし」と表示される。
7. 印刷用紙を確認する。通常は「自動」でA4、記載が多い月はA3になる。A4・A3を指定することもできる。「印刷 / PDF保存」を押し、月別集計・契約報告・備品棚卸・圧着数が載っていることを確認する。
8. プリンターで「PDFとして保存」または「Microsoft Print to PDF」を選ぶ。
9. 幹部会議フォルダーを保存先に指定し、対象月が分かるファイル名で保存する。
10. 保存したPDFを開き、対象月、ページの切れ、合計を確認する。

出力する契約表は、新規分・入替分それぞれ記載のある行だけを使い、未記載なら「記載なし」と表示する。圧着数は日別一覧を左右に並べ、全体を用紙1枚に収める。圧着数の報告には入力者名を載せない。報告の確認と出力はマーク管理の権限を持つ利用者が行う。

動画では、対象月選択、契約入力、圧着数の確認、PDFのプレビュー、幹部会議フォルダーへの保存、保存結果の確認を撮影する。

## 日々の記録 — 圧着カウンター

1. 日々の記録 → 圧着カウンターを開く。
2. 入力者、日付、カウンターの数値を選択・入力して保存する。
3. 対象月の記録と圧着数を確認する。
4. 幹部会議報告で使う月の末日まで、記録がそろっているか確認する。
