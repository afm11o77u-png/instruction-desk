# 倉庫QR読み取りの手順

## 倉庫に行く前（事務所のWi-Fi）

ホーム画面にアイコンを置く場合は、スマホページ上部の「ホーム画面にアイコンを追加する」の案内に従ってください。追加後は必ずそのアイコンから開き、同じ利用者でログインしてから準備します。ブラウザ内に未送信作業がある場合は先に送信し、以後は同じアイコンから利用してください。

1. 使用するスマホ・ブラウザでログインし、スマホ専用のQR読み取りページを開きます。
2. 「倉庫へ行く前の準備」を開き、「倉庫用の準備」を押します。
3. 準備完了の表示を確認し、ページを一度開き直します。
4. 初回はWi-Fiなどの通信を切り、同じページが開くことを確認します。

接続先のアドレス・使用するブラウザを変えると、保存先も別になります。事務所で使うアドレスで準備し、同じページをブックマークしてください。

## 倉庫（通信なし）

1. 「カメラON」で読み取ります。最初のQRで作業が始まります。
2. 同じQRは一度画面から外して再び映すと1枚追加します。
3. 枚数は＋・－や直接入力で変更できます。間違えた行は削除できます。
4. 「作業を完了（端末に保存）」を押します。編集内容も保存し、「作業完了・未送信」になります。

読み取った記録は端末内に保存します。作業完了では事務所への送信・在庫変更は行いません。

保存後に続きを行う場合は、保存した作業を選んで「この作業を再開」を押します。追加読み取り・枚数編集・行削除ができ、最後にもう一度「作業を完了」を押します。通信なしでも再開できます。別の読み取り中作業がある場合は先に完了してください。送信を開始した作業は、受信確認の食い違いを防ぐため再開できません。

## 事務所に戻ったら

1. 事務所のWi-Fiに接続します。
2. 対象の未送信作業を選び、「事務所へ送信」を押します。
3. 「送信済み」の表示を確認します。ログイン期限が切れていたら、元の担当者でログインしてから送信してください。

送信できなかった作業は端末に残ります。受信確認が返らなかった場合も、同じ作業を再送できます。別の作業として二重登録しません。

## PCでの確認

1. 在庫管理の「QR読み取り」で「一覧を更新」します。
2. 受信済みの作業を選び、制服・枚数・出庫／入庫・保管場所を確認します。
3. 入庫の場合は仕入単価も入力します。
4. 更新権限のある担当者が「確認して在庫に反映」を押します。PCでの編集内容も保存されます。

送信されるまで、スマホ内の作業はPCの受信一覧に出ません。PC自身で読み取る場合も、端末内保存→完了→送信→在庫反映の順です。

## 保存について

- 未送信作業がある間は、ブラウザのデータ消去・プライベートモードの利用を避けてください。
- 初回準備が完了していない端末では、倉庫での画面起動や商品名の表示ができません。
- 商品情報が変わったときは、事務所で準備を更新します。送信時はサーバーで商品対応を照合し直します。
- 段ボールの旧QRは引き継いだ対応表で読み取ります。通常のQR表示でも保存済みの旧QRを表示し、新しいIDへの置き換えはしません。「QR貼替対象」は従来どおり例外として確認します。
- 商品を照合できないQRはエラーを表示し、枚数・合計に加算しません。事務所に接続中なら既存QRの対応をサーバーでも確認し、照合できた情報を端末へ保存します。新しいIDは発行しません。
- 「倉庫用の準備」には保存した件数・日時と保存確認の結果を表示します。以前の未照合行は削除せず集計対象外にし、準備更新で照合するか、作業者が削除します。
- 従来のサーバー保存方式の途中作業は、準備時に対応するQRが確認でき、端末に別の読み取り中作業がなければ引き継ぎます。元の記録は送信まで残ります。

## スマホの文章をPCへ渡す

1. スマホのQRページで「文章をPCへ送る」を開き、ChatGPTの回答などを貼り付けます。
2. 事務所のWi-Fiで「文章を送信」を押します。通信できなかった文章は端末の未送信記録に残り、再送信できます。
3. PCも同じ利用者でログインし、QRページの「スマホから受け取った文章」→「受信一覧を更新」を押します。
4. 「全文をコピー」を押し、PCのChatGPTに貼り付けます。

文章の送受信はQRの作業・在庫数量とは独立しています。本文は50000文字までです。他の利用者の受信一覧には表示しません。
